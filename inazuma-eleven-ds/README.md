# Inazuma Eleven DS (prototype)

Projet séparé du reste du dépôt. Jeu jouable dans le navigateur, format double écran DS
(haut : terrain, bas : mini-carte, jauge de charge, stick et boutons tactiles).

Ouvrir `index.html` dans un navigateur.

Sprites perso : voir `sprites/LISEZMOI.txt`.

## Contrôles
| Action | Clavier | Tactile (écran du bas) |
|---|---|---|
| Stick | ZQSD / flèches | joystick à gauche |
| Dribble (sprint avec balle) | Espace | bouton DRIBBLE |
| Passe | K | bouton PASSE |
| Tir (maintenir = charger) | J | bouton TIR |

## Tirs chargés
Maintenir TIR : LVL 1 **Tornade de feu** → LVL 2 **Tempête de feu** → LVL 3 **Tornade de feu DD**.

## Histoire
6 matchs enchaînant IE1 → IE2 → IE3 (gagner débloque le suivant). Voir `CHAPTERS` dans `index.html`.
